# Nutzung / How to use

## Deutsch

1. **Dateien ablegen:** PDF (ZUGFeRD, Factur-X) oder XML (XRechnung, CII, UBL) auf die Fläche ziehen oder auswählen, bis zu 200 auf einmal.
2. **Ergebnis lesen:** Oben steht das Urteil. Darunter stehen die Prüfschritte und je Befund, was falsch ist und wie es behoben wird.
3. **Ansichten wechseln:**
   - **Bericht:** das Prüfergebnis
   - **Rechnung:** die Rechnungsdaten in lesbarer Form, Felder mit Befunden sind rot (Fehler) oder orange (Hinweis) markiert
   - **PDF:** das Original; in der Ansicht „Rechnung“ lässt es sich auf großen Bildschirmen auch daneben anzeigen
   - **XML:** die Rohdaten
4. **Bei mehreren Rechnungen** stehen Problemfälle oben. Über „ZIP herunterladen“ gibt es einen Excel-Bericht und je Rechnung einen Ordner, auf Wunsch mit der Rechnungsansicht als HTML.

**Was die Urteile bedeuten**

| Urteil | Bedeutung |
|---|---|
| Gültig | erfüllt die geprüften Regeln |
| Gültig mit Hinweisen | erfüllt die Regeln, einzelne Punkte sollten geprüft werden |
| Nicht gültig | mindestens ein Fehler; der Empfänger kann die Rechnung ablehnen |
| Keine E-Rechnung | eine PDF ohne eingebettete Rechnungsdaten |

Das Tool speichert nichts. Schließen Sie die Seite, sind alle Ergebnisse weg. Sichern Sie, was Sie brauchen, vorher per Download oder Druck. Der Bericht ist eine technische Prüfung und keine steuerliche Bewertung. Ob das PDF zu den Daten passt, prüft das Tool nicht automatisch; dafür ist die Ansicht „PDF daneben“ gedacht.

## English

1. **Add files:** drop or choose PDFs (ZUGFeRD, Factur-X) or XML files (XRechnung, CII, UBL), up to 200 at once.
2. **Read the result:** the verdict is at the top, followed by the checks and, for each finding, what is wrong and how to fix it.
3. **Switch views:**
   - **Report:** the validation result
   - **Invoice:** the invoice data in readable form, with fields highlighted in red (error) or orange (note)
   - **PDF:** the original; on large screens the Invoice view can also show it alongside
   - **XML:** the raw data
4. **With several invoices,** problem cases come first. "Download ZIP" gives you an Excel report and one folder per invoice, optionally with the invoice view as HTML.

**What the verdicts mean**

| Verdict | Meaning |
|---|---|
| Valid | meets the checked rules |
| Valid with notes | meets the rules; individual items should be reviewed |
| Not valid | at least one error; the recipient may reject the invoice |
| Not an e-invoice | a PDF without embedded invoice data |

The tool stores nothing. Closing the page discards all results, so save what you need first by downloading or printing it. The report is a technical check, not a tax assessment. The tool does not automatically compare the PDF with the data; use the "Show PDF alongside" view for that.
